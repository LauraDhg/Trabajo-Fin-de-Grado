Function "vault_program_id":
- Returns a Pubkey.
- This Pubkey is hardcoded.

Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches on the `InstructionFormat` enum to call the appropriate handler function.
- Dispatches to different instruction handlers based on the unpacked instruction.

Function "create_admin":
- Creates an admin account.
- Checks if the admin payer is a signer.
- Checks if the admin account has already been initialized.
- Derives the admin account's PDA.
- Checks if the provided admin account matches the derived PDA.
- Creates the admin account using `invoke_signed` and the system program.
- Serializes the admin account data.

Function "update_admin":
- Updates the admin account with a new admin.
- Checks if the admin payer is a signer.
- Checks if the admin account's owner is the program.
- Deserializes the admin account data.
- Derives the admin account's PDA.
- Checks if the provided admin account matches the derived PDA.
- Checks if the admin payer is the current admin.
- Updates the admin ID and last update timestamp.
- Serializes the updated admin account data.

Function "create_account":
- Creates a user account.
- Checks if the user payer is a signer.
- Checks if the user account has already been initialized.
- Derives the user account's PDA.
- Checks if the provided user account matches the derived PDA.
- Creates the user account using `invoke_signed` and the system program.
- Serializes the user account data.

Function "open_proposal":
- Creates a proposal account.
- Checks if the user account's owner is the program.
- Checks if the user payer is a signer.
- Checks if the proposal account has already been initialized.
- Derives the proposal account's PDA.
- Checks if the provided proposal account matches the derived PDA.
- Creates the proposal account using `invoke_signed` and the system program.
- Serializes the proposal data.
- Sets the proposal's end time to 1 hour after the start time.

Function "vote_process":
- Processes a vote on a proposal.
- Checks if the user account and proposal account owners are the program.
- Checks if the user payer is a signer.
- Checks if the vote record account has already been initialized.
- Derives the vote record account's PDA.
- Checks if the provided vote record account matches the derived PDA.
- Deserializes the proposal and user account data.
- Checks if the voting time limit has expired.
- Updates the yes or no vote count based on the vote answer.
- Creates the vote record account using `invoke_signed` and the system program.
- Serializes the vote record, proposal, and user account data.

Function "manage_governance_points":
- Manages governance points for a user.
- Checks if the admin account and user account owners are the program.
- Checks if the admin payer is a signer.
- Derives the admin account's PDA.
- Checks if the provided admin account matches the derived PDA.
- Deserializes the admin account data.
- Checks if the admin payer is the current admin.
- Deserializes the user account data.
- Adds or subtracts governance points from the user's account.
- Serializes the user account data.

Function "execute_instruction":
- Executes an instruction by CPI to the vault program.
- Checks if the user account's owner is the program.
- Checks if the user payer is a signer.
- Checks if the user account has lamports greater than 0.
- Performs different checks based on the variant instruction.
- Checks the previous instruction's program ID.
- Calls `send_create_vault_transaction` or `send_instr_to_vault_transaction` based on the variant instruction.

Function "make_decision":
- Makes a decision on a proposal.
- Checks if the admin account and proposal account owners are the program.
- Checks if the admin payer is a signer.
- Derives the admin account's PDA.
- Checks if the provided admin account matches the derived PDA.
- Deserializes the admin account data.
- Checks if the admin payer is the current admin.
- Deserializes the proposal data.
- Checks if the proposal is still active.
- Sets the `executed` flag on the proposal based on the vote outcome.
- Serializes the updated proposal data.
