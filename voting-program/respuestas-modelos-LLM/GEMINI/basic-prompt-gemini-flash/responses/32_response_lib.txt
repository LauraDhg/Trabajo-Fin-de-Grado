```
Function "vault_program_id":
- Returns a Pubkey.
- The Pubkey is hardcoded.

Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the instruction to a corresponding handler function.
- Calls the handler function with the program ID, accounts, and relevant data.

Function "create_admin":
- Creates an admin account.
- Checks if the `admin_payer` account is a signer.
- Checks if the `admin_account_dao` account is already initialized.
- Derives the admin account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `admin_account_dao` matches the derived PDA.
- Creates the admin account using `system_instruction::create_account` and `invoke_signed`.
- Serializes an `Admin_Account` struct into the newly created account.

Function "update_admin":
- Updates the admin account with a new admin Pubkey.
- Checks if the `admin_account_dao` account is owned by the program.
- Checks if the `admin_payer` account is a signer.
- Deserializes the `Admin_Account` from the provided account.
- Derives the admin account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `admin_account_dao` matches the derived PDA.
- Updates the `admin_id` field in the `Admin_Account` struct.
- Serializes the updated `Admin_Account` back into the account.

Function "create_account":
- Creates a user account.
- Checks if the `user_payer` account is a signer.
- Checks if the `user_account_dao` account is already initialized.
- Derives the user account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `user_account_dao` matches the derived PDA.
- Creates the user account using `system_instruction::create_account` and `invoke_signed`.
- Serializes a `User_Account` struct into the newly created account, initializing governance points to 10.

Function "open_proposal":
- Creates a proposal account.
- Checks if the `user_account_dao` account is owned by the program.
- Checks if the `user_payer` account is a signer.
- Checks if the `proposal_account` account is already initialized.
- Derives the proposal account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `proposal_account` matches the derived PDA.
- Deserializes the `User_Account` from the provided account.
- Checks if the account type is `User`.
- Creates the proposal account using `system_instruction::create_account` and `invoke_signed`.
- Serializes a `Proposal` struct into the newly created account.

Function "vote_process":
- Processes a vote on a proposal.
- Checks if the `user_account_dao` and `proposal_account` accounts are owned by the program.
- Checks if the `user_payer` account is a signer.
- Checks if the `vote_record_account` account is already initialized.
- Derives the vote record's PDA using `Pubkey::find_program_address`.
- Checks if the provided `vote_record_account` matches the derived PDA.
- Deserializes the `Proposal` and `User_Account` from the provided accounts.
- Checks if the account type is `User`.
- Checks if the current time is within the proposal's voting period.
- Updates the `yes_votes` or `no_votes` count on the proposal based on the `vote_answer`.
- Creates the vote record account using `system_instruction::create_account` and `invoke_signed`.
- Serializes a `Vote_Record` struct into the newly created account.
- Serializes the updated `Proposal` and `User_Account` structs back into their accounts.

Function "manage_governance_points":
- Adds or subtracts governance points from a user account.
- Checks if the `admin_account_dao` and `user_account_dao` accounts are owned by the program.
- Checks if the `admin_payer` account is a signer.
- Derives the admin account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `admin_account_dao` matches the derived PDA.
- Deserializes the `User_Account` from the provided account.
- Checks if the account type is `User`.
- Adds or subtracts the specified `amount` from the user's `amount_governance_points`.
- Serializes the updated `User_Account` back into the account.

Function "execute_instruction":
- Executes an instruction by calling another program.
- Checks if the `user_account_dao` account is owned by the program.
- Checks if the `user_payer` account is a signer.
- Checks if the `user_account_dao` account is initialized.
- Performs different checks and actions based on the `variant_instr`.
- Loads the current instruction index from the instructions sysvar.
- Checks if the previous instruction was from the vault program.
- Calls `send_create_vault_transaction` or `send_instr_to_vault_transaction` based on `variant_instr`.

Function "make_decision":
- Makes a decision on a proposal based on the vote count.
- Checks if the `admin_account_dao` and `proposal_account` accounts are owned by the program.
- Checks if the `admin_payer` account is a signer.
- Derives the admin account's PDA using `Pubkey::find_program_address`.
- Checks if the provided `admin_account_dao` matches the derived PDA.
- Deserializes the `Proposal` from the provided account.
- Checks if the current time is after the proposal's end time.
- Sets the `executed` field on the proposal to `true`.
- Serializes the updated `Proposal` back into the account.
```
