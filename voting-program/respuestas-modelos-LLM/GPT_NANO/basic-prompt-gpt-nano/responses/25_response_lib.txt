Function "send_create_vault_transaction":
- Constructs and sends a create vault instruction to the vault program with specified accounts and data.
- Uses invoke_signed to perform CPI (Cross-Program Invocation) with PDA-derived seed.

Function "send_instr_to_vault_transaction":
- Constructs and sends a transaction instruction to the vault program for deposit or withdrawal with specified accounts and data.
- Uses invoke_signed to perform CPI with PDA-derived seed.

Function "process_instruction":
- Entry point for the program, unpacks instruction data and dispatches to corresponding function based on instruction type.
- Uses pattern matching on instruction enum to call appropriate handling functions.

Function "create_admin":
- Creates and initializes an admin account PDA with required rent exemption.
- Checks signatures and account ownership.
- Serializes admin details into account data.

Function "update_admin":
- Updates the admin account PDA with a new admin ID and timestamp.
- Checks signatures and account ownership.
- Deserializes, modifies, and re-serializes admin account data.

Function "create_account":
- Creates a user account PDA with default governance points.
- Checks signature and account existence.
- Serializes user account data.

Function "open_proposal":
- Creates a proposal account PDA with proposal details.
- Checks account ownership and signatures.
- Sets start and end time, serializes proposal data.

Function "vote_process":
- Handles voting on a proposal, updating vote counts.
- Creates a vote record account.
- Checks for time limits and previous votes.
- Serializes updated proposal, vote record, and user account.

Function "manage_governance_points":
- Adds or subtracts governance points from a user.
- Checks signatures and account ownership.
- Serializes updated user account.

Function "execute_instruction":
- Validates instruction, account ownership, and signatures.
- Checks previous instruction via sysvar.
- Calls send_create_vault_transaction or send_instr_to_vault_transaction based on instruction.

Function "make_decision":
- Finalizes a proposal by determining if it is approved or denied after end time.
- Checks signatures and account ownership.
- Sets proposal as executed and records decision.
