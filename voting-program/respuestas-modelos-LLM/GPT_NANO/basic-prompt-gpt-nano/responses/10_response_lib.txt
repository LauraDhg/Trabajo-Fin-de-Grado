Function "send_create_vault_transaction":
- Constructs and sends an instruction to create a vault account.
- Prepares instruction data and account metas.
- Uses invoke_signed to execute cross-program invocation with seeds for PDA.

Function "send_instr_to_vault_transaction":
- Constructs and sends an instruction to interact with the vault (deposit/withdraw).
- Prepares instruction data and account metas.
- Uses invoke_signed to execute cross-program invocation with seeds for PDA.

Function "process_instruction":
- Entry point for processing instructions.
- Unpacks the instruction data.
- Routes to specific functions based on instruction type.

Function "create_admin":
- Creates an admin account and initializes it if it doesn't exist.
- Checks signatures and account ownership.
- Calculates rent exemption and uses invoke_signed to create account.
- Serializes admin data into account.

Function "update_admin":
- Updates the admin account with a new admin ID.
- Checks account ownership and signatures.
- Deserializes, modifies, and re-serializes admin data.

Function "create_account":
- Creates a user account for governance points.
- Checks signatures, ownership, and account initialization.
- Calculates rent and creates account via invoke_signed.
- Serializes user info into account.

Function "open_proposal":
- Creates a proposal account with details.
- Checks signatures, ownership, account state.
- Uses system_instruction::create_account with PDA derivation.
- Initializes proposal data.

Function "vote_process":
- Records a user's vote on a proposal.
- Checks signatures and ownership.
- Checks if voting period is active.
- Updates proposal vote counts with checked arithmetic.
- Creates a vote record account.
- Serializes updated data for proposal, user, and vote record.

Function "manage_governance_points":
- Adds or subtracts governance points for a user.
- Checks signatures and ownership.
- Deserialize, modify, serialize user account data.
- Uses checked arithmetic for safety.

Function "execute_instruction":
- Executes different instructions for vault management based on variant.
- Checks signatures, ownership, and program IDs.
- Loads previous instruction from sysvar and logs info.
- Calls send_create_vault_transaction or send_instr_to_vault_transaction accordingly.

Function "make_decision":
- Finalizes a proposal and makes a decision.
- Checks signatures, ownership.
- Checks if proposal period has ended based on timestamp.
- Logs whether proposal was approved or denied.
- Marks proposal as executed and serializes.
