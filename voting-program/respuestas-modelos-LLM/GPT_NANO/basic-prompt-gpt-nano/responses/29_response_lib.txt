Function "send_create_vault_transaction":
- Constructs and sends a transaction to create a vault by invoking another program.
- Sets up instruction data and accounts, including seeds for signers.
- Uses invoke_signed to perform cross-program invocation with signing seeds.

Function "send_instr_to_vault_transaction":
- Constructs and sends a transaction to interact with the vault (deposit/withdraw).
- Sets instruction data with amount and proposal ID.
- Uses invoke_signed with signing seeds to perform the cross-program invocation.

Function "process_instruction":
- Entry point for the program, dispatching logic based on instruction data.
- Unpacks instruction data and routes to respective functions (create_admin, update_admin, etc.).

Function "create_admin":
- Creates and initializes an admin account with program-derived address (PDA).
- Sets admin ID and last update timestamp.
- Uses invoke_signed to create the account with rent exemption.

Function "update_admin":
- Updates the admin account with a new admin ID and timestamp.
- Checks owner, signer, and verify correct PDA, then serializes updated data.

Function "create_account":
- Creates a user account with a PDA, initializing governance points.
- Uses invoke_signed for account creation and rent exemption.

Function "open_proposal":
- Creates a new proposal account with PDA, including title and description.
- Sets start and end times based on the clock.
- Uses invoke_signed for creating the account and serializing data.

Function "vote_process":
- Records a vote by creating a vote record account via PDA.
- Checks proposal timing, updates votes, and serializes all data.
- Uses invoke_signed to create vote record account.

Function "manage_governance_points":
- Adds or subtracts governance points for a user, validated by admin privileges.
- Checks owner, signer, and correct admin PDA.
- Serializes the updated user governance points.

Function "execute_instruction":
- Executes different actions (create vault, deposit, withdraw) based on instruction variant.
- Validates owner, signer, and program IDs for vault and instruction sysvar.
- Loads previous instruction, calls respective functions for vault interactions.
- Uses invoke_signed for cross-program calls.

Function "make_decision":
- Finalizes a proposal, marking it as executed.
- Checks owner, signer, admin privileges, and proposal timing.
- Compares votes and outputs decision.
- Serializes the proposal as executed.
