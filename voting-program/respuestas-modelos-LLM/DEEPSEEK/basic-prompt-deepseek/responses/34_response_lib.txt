Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses Pubkey::from_str with a fixed string
- Unwraps the result, which could panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string description
- Matches 0 to "Create", 1 to "Deposit", 2 to "Withdraw"
- Returns "Unknown" for any other value

Function "send_create_vault_transaction":
- Constructs instruction data for vault creation
- Uses invoke_signed to call an external vault program
- Includes system program in account metas
- Uses vault_bump for PDA derivation

Function "send_instr_to_vault_transaction":
- Constructs instruction data for vault operations (deposit/withdraw)
- Uses invoke_signed to call an external vault program
- Does not include system program in account metas
- Uses vault_bump for PDA derivation

Function "process_instruction":
- Entry point for the program
- Unpacks instruction data using InstructionFormat
- Routes to appropriate handler function based on instruction variant

Function "create_admin":
- Creates an admin PDA account
- Validates signer and account ownership
- Uses system_instruction::create_account via invoke_signed
- Stores admin ID and timestamp in account data

Function "update_admin":
- Updates the admin account with a new admin ID
- Validates current admin privileges
- Updates timestamp
- Requires signer to be current admin

Function "create_account":
- Creates a user PDA account
- Initializes with 10 governance points
- Uses system_instruction::create_account via invoke_signed
- Validates signer and account ownership

Function "open_proposal":
- Creates a proposal PDA account
- Sets start and end times (1 hour duration)
- Validates user account ownership
- Uses system_instruction::create_account via invoke_signed

Function "vote_process":
- Records a vote on a proposal
- Validates proposal is still active
- Creates vote record PDA account
- Adds user's governance points to vote count
- Uses checked_add for arithmetic safety

Function "manage_governance_points":
- Adds or subtracts governance points from user account
- Requires admin privileges
- Uses checked_add for addition but unchecked subtraction
- Validates account types and ownership

Function "execute_instruction":
- Executes vault operations (create, deposit, withdraw)
- Validates account types based on operation
- Checks previous instruction for vault program confirmation
- Calls appropriate send transaction function

Function "make_decision":
- Finalizes proposal execution after end time
- Compares yes vs no votes
- Marks proposal as executed
- Validates admin privileges and timing
