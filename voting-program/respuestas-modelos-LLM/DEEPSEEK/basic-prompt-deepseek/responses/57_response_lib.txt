Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses unwrap which can panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string representation
- Handles unknown actions by returning "Unknown"

Function "send_create_vault_transaction":
- Constructs an instruction for creating a vault
- Uses invoke_signed to call the vault program
- Includes system program in accounts
- Uses vault_bump for PDA derivation

Function "send_instr_to_vault_transaction":
- Constructs instructions for deposit/withdraw operations
- Uses invoke_signed to call the vault program
- Does not include system program in accounts
- Uses vault_bump for PDA derivation

Function "process_instruction":
- Main entry point that unpacks and routes instructions
- Matches against InstructionFormat enum variants
- Calls appropriate handler functions based on instruction type

Function "create_admin":
- Creates admin PDA account
- Checks for signer and account initialization
- Uses system_instruction::create_account
- Stores admin ID and timestamp
- Uses admin_bump for PDA derivation

Function "update_admin":
- Updates admin account with new admin ID
- Verifies account ownership and signer
- Updates timestamp
- Uses admin_bump for PDA verification

Function "create_account":
- Creates user PDA account
- Initializes with 10 governance points
- Uses system_instruction::create_account
- Uses user_bump and user pubkey for PDA derivation

Function "open_proposal":
- Creates proposal PDA account
- Sets 1-hour voting period from current time
- Stores proposal metadata and voting state
- Uses proposal_bump and title for PDA derivation

Function "vote_process":
- Processes user votes on proposals
- Creates vote record PDA
- Checks voting period validity
- Updates proposal vote counts
- Uses vote_bump for PDA derivation

Function "manage_governance_points":
- Adds or subtracts governance points from users
- Requires admin authorization
- Performs arithmetic operations with overflow checks
- Updates user account data

Function "execute_instruction":
- Executes vault operations (create/deposit/withdraw)
- Verifies account types based on instruction variant
- Checks previous instruction for vault program confirmation
- Calls appropriate vault transaction functions
- Uses user_bump for account verification

Function "make_decision":
- Finalizes proposal execution after voting period
- Compares yes/no votes to determine outcome
- Marks proposal as executed
- Requires admin authorization
- Uses admin_bump for PDA verification
