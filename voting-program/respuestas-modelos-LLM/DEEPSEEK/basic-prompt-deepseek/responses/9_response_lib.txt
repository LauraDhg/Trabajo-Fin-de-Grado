Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses unwrap which could panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string representation
- Returns "Create" for 0, "Deposit" for 1, "Withdraw" for 2, "Unknown" for other values

Function "send_create_vault_transaction":
- Creates and sends a cross-program invocation to create a vault
- Uses invoke_signed with vault seeds for PDA signing
- Constructs instruction data with variant, pubkey, and bump
- Includes system program in account metas

Function "send_instr_to_vault_transaction":
- Creates and sends cross-program invocations for deposit/withdraw operations
- Uses invoke_signed with vault seeds
- Constructs instruction data with variant, amount, and pubkey
- Does not include system program in account metas

Function "process_instruction":
- Main entry point that unpacks and routes instructions
- Matches on InstructionFormat enum variants
- Calls appropriate handler functions based on instruction type

Function "create_admin":
- Creates admin PDA account with program-derived address
- Validates signer and account ownership
- Checks account is not already initialized
- Uses system_instruction::create_account with invoke_signed
- Stores admin ID and timestamp in account data

Function "update_admin":
- Updates the admin account with a new admin pubkey
- Validates current admin privileges and ownership
- Updates timestamp on admin change
- Requires signer to be current admin

Function "create_account":
- Creates user account PDA with initial governance points
- Uses user's pubkey as part of PDA seeds
- Initializes with 10 governance points
- Validates signer and account not initialized

Function "open_proposal":
- Creates proposal account with title and description
- Sets voting period to 1 hour from creation
- Uses proposal title as part of PDA seeds
- Validates user account ownership and signer

Function "vote_process":
- Processes user votes on proposals
- Creates vote record account for tracking
- Validates voting period is active
- Adds user's governance points to yes/no votes
- Checks for arithmetic overflow

Function "manage_governance_points":
- Admin function to add/subtract governance points from users
- Validates admin privileges
- Uses checked_add for addition but unchecked subtraction
- Updates user account governance points

Function "execute_instruction":
- Executes cross-program calls to vault program
- Validates different account types based on instruction variant
- Checks previous instruction was from vault program
- Routes to appropriate send transaction functions

Function "make_decision":
- Finalizes proposal voting and determines outcome
- Validates voting period has ended
- Compares yes/no votes to determine result
- Marks proposal as executed
- Requires admin privileges
