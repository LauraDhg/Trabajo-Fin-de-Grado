Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses unwrap which could panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string description
- Returns "Unknown" for invalid action codes

Function "send_create_vault_transaction":
- Constructs an instruction for creating a vault
- Uses invoke_signed to call the vault program
- Includes system program in the account list
- Uses vault_bump for PDA signing

Function "send_instr_to_vault_transaction":
- Constructs instructions for deposit/withdraw operations
- Uses invoke_signed to call the vault program
- Does not include system program in account list
- Uses vault_bump for PDA signing

Function "process_instruction":
- Entry point that unpacks instruction data
- Routes to different functions based on instruction type
- Handles all supported instruction formats

Function "create_admin":
- Creates an admin account PDA
- Validates signer and account state
- Uses system_instruction::create_account
- Stores admin ID and timestamp
- Checks for account already initialized

Function "update_admin":
- Updates admin account with new admin ID
- Validates current admin privileges
- Updates timestamp
- Checks PDA address matches

Function "create_account":
- Creates user account PDA
- Initializes with 10 governance points
- Uses system_instruction::create_account
- Validates signer and account state

Function "open_proposal":
- Creates proposal account PDA
- Sets 1-hour voting period
- Stores proposal metadata and voting state
- Uses title bytes for PDA derivation

Function "vote_process":
- Processes user votes on proposals
- Creates vote record account
- Checks voting period validity
- Uses checked arithmetic to prevent overflow
- Updates proposal vote counts

Function "manage_governance_points":
- Admin function to modify user governance points
- Validates admin privileges
- Supports adding or subtracting points
- Uses checked arithmetic

Function "execute_instruction":
- Executes vault operations (create/deposit/withdraw)
- Validates user privileges based on operation type
- Checks previous instruction for vault program confirmation
- Calls appropriate vault transaction function

Function "make_decision":
- Finalizes proposal voting results
- Validates admin privileges
- Checks voting period has ended
- Marks proposal as executed
- Compares yes/no votes for decision
