Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses unwrap which could panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string description
- Returns "Unknown" for any value not 0, 1, or 2

Function "send_create_vault_transaction":
- Constructs a cross-program instruction for vault creation
- Uses invoke_signed with program-derived addresses
- Includes system program in account metas

Function "send_instr_to_vault_transaction":
- Constructs cross-program instructions for vault operations
- Handles deposit and withdraw operations
- Uses invoke_signed with program-derived addresses

Function "process_instruction":
- Main entry point that routes to different instructions
- Unpacks instruction data using InstructionFormat
- Matches on different instruction variants

Function "create_admin":
- Creates an admin account with program-derived address
- Validates signer and account ownership
- Uses system_instruction::create_account with invoke_signed
- Stores admin ID and timestamp

Function "update_admin":
- Updates the admin account with a new admin ID
- Validates current admin is signer
- Updates timestamp on change
- Uses program-derived address validation

Function "create_account":
- Creates a user account with initial governance points
- Uses program-derived address based on user pubkey
- Validates signer and account initialization status
- Uses system_instruction::create_account with invoke_signed

Function "open_proposal":
- Creates a new proposal account
- Sets start and end times (1 hour duration)
- Validates user account ownership
- Uses program-derived address based on proposal title

Function "vote_process":
- Processes a vote on a proposal
- Creates vote record account
- Validates voting period is active
- Updates proposal vote counts with user's governance points
- Uses checked arithmetic to prevent overflow

Function "manage_governance_points":
- Adds or subtracts governance points from user accounts
- Requires admin authorization
- Uses checked addition but unchecked subtraction
- Validates admin account using program-derived address

Function "execute_instruction":
- Executes cross-program instructions to vault program
- Validates instruction sysvar and previous instruction
- Routes to different vault operations based on variant
- Uses program-derived address validation for different account types

Function "make_decision":
- Finalizes proposal voting and determines outcome
- Validates voting period has ended
- Compares yes vs no votes
- Marks proposal as executed
- Requires admin authorization
