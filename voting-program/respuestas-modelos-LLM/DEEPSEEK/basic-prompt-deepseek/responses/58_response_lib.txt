Function "vault_program_id":
- Returns a hardcoded Pubkey for a vault program
- Uses from_str and unwrap which may panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string description
- Matches 0 to "Create", 1 to "Deposit", 2 to "Withdraw", others to "Unknown"

Function "send_create_vault_transaction":
- Constructs and sends a cross-program instruction to a vault program
- Uses invoke_signed with vault seeds for PDA signing
- Creates instruction data with variant, pubkey, and bump
- Includes system program in account metas

Function "send_instr_to_vault_transaction":
- Constructs and sends vault operation instructions
- Creates instruction data with variant, amount, and pubkey
- Uses invoke_signed with vault seeds
- Does not include system program in account metas

Function "process_instruction":
- Main entry point that unpacks and routes instructions
- Matches on InstructionFormat enum variants
- Calls appropriate handler functions based on instruction type

Function "create_admin":
- Creates an admin PDA account
- Validates signer and account ownership
- Checks for existing initialization
- Uses invoke_signed to create account with admin seeds
- Stores admin ID and timestamp

Function "update_admin":
- Updates the admin account with a new admin ID
- Validates signer and account ownership
- Updates timestamp on change
- Verifies PDA address matches expected

Function "create_account":
- Creates a user PDA account with initial governance points
- Validates signer and account ownership
- Uses user's pubkey in PDA seeds
- Initializes with 10 governance points

Function "open_proposal":
- Creates a proposal PDA account
- Validates user account and signer
- Sets proposal duration to 1 hour from creation
- Stores proposal metadata and voting counters

Function "vote_process":
- Processes a vote on a proposal
- Creates vote record PDA account
- Validates proposal is still active
- Adds user's governance points to yes/no votes
- Prevents double voting by checking vote account initialization

Function "manage_governance_points":
- Adds or subtracts governance points from user accounts
- Requires admin authorization
- Validates account types and ownership
- Performs arithmetic operations on point balances

Function "execute_instruction":
- Executes cross-program instructions to vault
- Validates account types based on instruction variant
- Checks previous instruction for vault program confirmation
- Routes to appropriate vault transaction functions

Function "make_decision":
- Finalizes proposal voting and determines outcome
- Validates proposal has ended
- Compares yes/no votes and marks proposal as executed
- Requires admin authorization
