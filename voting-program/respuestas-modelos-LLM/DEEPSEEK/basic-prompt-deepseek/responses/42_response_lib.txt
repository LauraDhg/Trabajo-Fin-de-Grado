Function "vault_program_id":
- Returns a hardcoded Pubkey for the vault program
- Uses from_str and unwrap which could panic if the string is invalid

Function "action_as_str":
- Converts a u8 action code to a string description
- Returns "Create" for 0, "Deposit" for 1, "Withdraw" for 2, "Unknown" for other values

Function "send_create_vault_transaction":
- Constructs and sends a cross-program invocation to create a vault
- Uses invoke_signed with vault seeds for PDA signing
- Includes system program in account metas

Function "send_instr_to_vault_transaction":
- Constructs and sends a cross-program invocation for vault operations
- Uses invoke_signed with vault seeds for PDA signing
- Handles deposit and withdraw operations

Function "process_instruction":
- Main entry point that unpacks instruction data
- Routes to appropriate handler functions based on instruction variant
- Handles multiple instruction types including CreateAdmin, UpdateAdmin, CreateAccount, etc.

Function "create_admin":
- Creates an admin account PDA
- Validates signer and account ownership
- Checks if account is already initialized
- Uses system_instruction::create_account with PDA seeds
- Stores admin ID and timestamp

Function "update_admin":
- Updates the admin account with a new admin ID
- Validates signer and account ownership
- Updates timestamp with current clock time
- Requires current admin signature

Function "create_account":
- Creates a user account PDA
- Validates signer and account ownership
- Initializes with 10 governance points
- Uses system_instruction::create_account with PDA seeds

Function "open_proposal":
- Creates a proposal account PDA
- Validates signer and account ownership
- Sets proposal start and end times (1 hour duration)
- Stores proposal metadata and voting state

Function "vote_process":
- Processes a vote on a proposal
- Validates signer and account ownership
- Checks if voting period is still active
- Creates vote record account
- Updates proposal vote counts with user's governance points

Function "manage_governance_points":
- Adds or subtracts governance points from a user
- Validates admin signature and account ownership
- Uses checked_sub to prevent underflow
- Only callable by admin accounts

Function "execute_instruction":
- Executes cross-program invocations to vault program
- Validates signer and account ownership
- Checks instruction history to prevent replay attacks
- Routes to appropriate vault operation functions
- Validates vault program ID matches expected value

Function "make_decision":
- Finalizes proposal execution after voting period
- Validates admin signature and account ownership
- Compares yes/no votes to determine outcome
- Marks proposal as executed
- Prevents execution before voting period ends
