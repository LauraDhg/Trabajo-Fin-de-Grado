Function "process_instruction":
- Unpacks instruction data using InstructionFormat::unpack
- Routes to appropriate function based on instruction type
- Handles CreateAccount, IncreaseAmount, WithdrawAmount, and TransferAmount instructions

Function "initialize_wallet_account":
- Creates a new wallet account as a PDA using "wallet" prefix and user account key
- Verifies system program account is provided
- Checks user account is signer
- Validates PDA derivation matches provided wallet account
- Prevents re-initialization by checking lamports > 0
- Calculates required rent for wallet account
- Uses invoke_signed with PDA bump seed for account creation
- Serializes initial wallet state with amount 0 and initialized true

Function "deposit_amount":
- Increases wallet balance by specified amount
- Verifies wallet account is owned by the program
- Checks user account is signer
- Validates PDA derivation matches provided wallet account
- Deserializes wallet data from account
- Ensures wallet is initialized before operation
- Performs unchecked addition (potential arithmetic overflow risk)
- Serializes updated wallet state

Function "withdraw_amount":
- Decreases wallet balance by specified amount
- Verifies wallet account is owned by the program
- Checks user account is signer
- Validates PDA derivation matches provided wallet account
- Deserializes wallet data from account
- Ensures wallet is initialized before operation
- Checks for sufficient funds before withdrawal
- Uses checked_sub to prevent underflow (safe arithmetic)
- Serializes updated wallet state

Function "transfer_amount":
- Transfers amount from source wallet to destination wallet
- Verifies both wallet accounts are owned by the program
- Checks user account is signer
- Validates PDA derivations for both wallets
- Deserializes both wallet accounts
- Ensures both wallets are initialized
- Performs unchecked addition on destination wallet (potential arithmetic overflow risk)
- Checks for sufficient funds in source wallet
- Uses checked_sub on source wallet (safe arithmetic)
- Serializes both updated wallet states
