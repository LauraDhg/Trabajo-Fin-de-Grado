Function "process_instruction":
- Unpacks instruction data using InstructionFormat::unpack
- Matches instruction variant to call appropriate handler function
- Handles CreateAccount, IncreaseAmount, WithdrawAmount, and TransferAmount operations

Function "initialize_wallet_account":
- Creates a new wallet account using PDA derivation with "wallet" prefix and user key
- Validates system program account matches expected ID
- Checks user account is signer
- Verifies wallet account has zero lamports (not initialized)
- Calculates required rent for wallet account size
- Uses invoke_signed to create account with proper PDA seeds
- Serializes initial wallet state with zero amount and initialized flag

Function "deposit_amount":
- Increases wallet amount by specified value
- Validates wallet account is owned by the program
- Verifies user account is signer
- Deserializes current wallet state
- Checks wallet is initialized
- Performs unchecked addition (potential arithmetic overflow risk)
- Serializes updated wallet state

Function "withdraw_amount":
- Decreases wallet amount by specified value
- Validates wallet account is owned by the program
- Verifies user account is signer
- Deserializes current wallet state
- Checks wallet is initialized
- Performs unchecked subtraction (potential arithmetic underflow/overflow risk)
- No validation that withdrawal amount doesn't exceed current balance
- Serializes updated wallet state

Function "transfer_amount":
- Transfers amount between two wallets
- Validates both source and destination wallets are owned by the program
- Verifies user account is signer
- Deserializes both wallet states
- Checks both wallets are initialized
- Performs unchecked addition and subtraction (potential arithmetic overflow/underflow risks)
- No validation that transfer amount doesn't exceed source wallet balance
- Serializes both updated wallet states
