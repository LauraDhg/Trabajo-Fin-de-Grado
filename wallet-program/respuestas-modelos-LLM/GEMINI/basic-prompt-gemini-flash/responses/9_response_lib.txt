Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the unpacked instruction and calls the corresponding handler function: `initialize_wallet_account`, `deposit_amount`, `withdraw_amount`, or `transfer_amount`.

Function "initialize_wallet_account":
- Retrieves accounts from the `accounts` slice using an iterator. It expects a user account, a wallet account (PDA), and the system program.
- Validates that the system program account is the correct system program.
- Checks that the user account is a signer.
- Derives the Program Derived Address (PDA) for the wallet account using `Pubkey::find_program_address`.
- Checks if the wallet account has already been initialized (lamports > 0), and returns an error if it has.
- Creates a `Wallet` struct with `amount = 0` and `initialized = true`.
- Calculates the rent-exempt balance for the wallet account.
- Invokes the system program to create the wallet account, signing with the PDA's seed and bump seed.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Retrieves the user and wallet accounts.
- Checks if the wallet account's owner is the program.
- Checks if the user is a signer.
- Deserializes the `Wallet` struct from the wallet account's data.
- Checks if the wallet is initialized.
- Adds the deposit amount to the wallet's amount using `checked_add` to prevent overflows, returning an `ArithmeticError` if an overflow occurs.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "withdraw_amount":
- Retrieves the user and wallet accounts.
- Checks if the wallet account's owner is the program.
- Checks if the user is a signer.
- Deserializes the `Wallet` struct from the wallet account's data.
- Checks if the wallet is initialized.
- Subtracts the withdrawal amount from the wallet's amount. **Potential vulnerability: Does not check for underflow, which can lead to the wallet having a very large amount.**
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Retrieves the user, source wallet, destination user, and destination wallet accounts.
- Checks if both source and destination wallet account owners are the program.
- Checks if the user is a signer.
- Deserializes the `Wallet` struct from both source and destination wallet accounts' data.
- Checks if both wallets are initialized.
- Adds the transfer amount to the destination wallet's amount using `checked_add` to prevent overflows.
- Subtracts the transfer amount from the source wallet's amount. **Potential vulnerability: Does not check for underflow in the source wallet, allowing for a large amount to be created.**
- Serializes the updated `Wallet` structs back into their respective wallet account's data.
