Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the instruction type and calls the appropriate handler function: `initialize_wallet_account`, `deposit_amount`, `withdraw_amount`, or `transfer_amount`.

Function "initialize_wallet_account":
- Retrieves account information: user account, wallet account, and system program account.
- Checks if the user account is a signer.
- Derives the Program Derived Address (PDA) for the wallet account using `Pubkey::find_program_address`.
- Validates that the provided wallet account matches the derived PDA.
- Checks if the wallet account has already been initialized (lamports > 0).
- Creates a `Wallet` struct with an initial amount of 0 and sets `initialized` to true.
- Calculates the rent-exempt minimum balance for the wallet account.
- Invokes the system program to create the wallet account, transferring the rent-exempt balance. The PDA bump seed is passed for signing.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Retrieves account information: user account and wallet account.
- Checks if the user account is a signer.
- Derives the PDA for the wallet account.
- Validates that the provided wallet account matches the derived PDA.
- Deserializes the wallet account data into a `Wallet` struct.
- Checks if the wallet has been initialized.
- Increases the wallet's `amount` by the specified `amount`.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "withdraw_amount":
- Retrieves account information: user account and wallet account.
- Checks if the user account is a signer.
- Derives the PDA for the wallet account.
- Validates that the provided wallet account matches the derived PDA.
- Deserializes the wallet account data into a `Wallet` struct.
- Checks if the wallet has been initialized.
- Decreases the wallet's `amount` by the specified `amount`.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Retrieves account information: user account, source wallet account, destination user account, and destination wallet account.
- Checks if the user account is a signer.
- Derives the PDAs for both the source and destination wallet accounts.
- Validates that the provided wallet accounts match the derived PDAs.
- Deserializes both the source and destination wallet account data into `Wallet` structs.
- Checks if both wallets have been initialized.
- Increases the destination wallet's `amount` by the specified `amount`.
- Decreases the source wallet's `amount` by the specified `amount`.
- Serializes the updated `Wallet` structs back into their respective wallet account data.
