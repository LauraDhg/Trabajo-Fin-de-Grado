Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the unpacked instruction and calls the corresponding handler function: `initialize_wallet_account`, `deposit_amount`, `withdraw_amount`, or `transfer_amount`.

Function "initialize_wallet_account":
- Retrieves account information using `next_account_info`. This includes the user account, the wallet account (PDA), and the system program account.
- Derives the PDA for the wallet account using `Pubkey::find_program_address`.
- Validates that the provided wallet account matches the derived PDA.
- Checks if the wallet account has already been initialized (lamports > 0).
- Creates a `Wallet` struct with `amount = 0` and `initialized = true`.
- Calculates the rent-exempt minimum balance for the wallet account.
- Invokes the system program to create the wallet account using `invoke_signed`.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Retrieves the user and wallet accounts using `next_account_info`.
- Derives the PDA for the wallet account.
- Validates that the provided wallet account matches the derived PDA.
- Deserializes the `Wallet` struct from the wallet account's data.
- Checks if the wallet is initialized.
- Adds the deposit amount to the wallet's amount, using `checked_add` to prevent overflow and returning a custom error if overflow occurs.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "withdraw_amount":
- Retrieves the user and wallet accounts.
- Derives the PDA for the wallet account.
- Validates that the provided wallet account matches the derived PDA.
- Deserializes the `Wallet` struct from the wallet account's data.
- Checks if the wallet is initialized.
- Subtracts the withdrawal amount from the wallet's amount. **Potential vulnerability: No overflow/underflow check is performed here. If `amount` is greater than `wallet.amount`, the subtraction will underflow, leading to a very large value in `wallet.amount`.**
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Retrieves the sender's user account and wallet account, and the receiver's user account and wallet account.
- Derives the PDAs for both the source and destination wallet accounts.
- Validates that the provided wallet accounts match the derived PDAs.
- Deserializes the `Wallet` structs from both the source and destination wallet accounts' data.
- Checks if both wallets are initialized.
- Adds the transfer amount to the destination wallet's amount, using `checked_add` to prevent overflow.
- Subtracts the transfer amount from the source wallet's amount. **Potential vulnerability: No overflow/underflow check is performed here. If `amount` is greater than `src_wallet.amount`, the subtraction will underflow, leading to a very large value in `src_wallet.amount`.**
- Serializes the updated `Wallet` structs back into their respective account data.
