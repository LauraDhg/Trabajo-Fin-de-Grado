Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the unpacked instruction and calls the corresponding function.
- Possible instructions are: `CreateAccount`, `IncreaseAmount`, `WithdrawAmount`, and `TransferAmount`.

Function "initialize_wallet_account":
- Initializes a new wallet account.
- Retrieves account information from the `accounts` slice: user account, wallet account, and system program.
- Validates that the system program is the correct one and the user account is a signer.
- Derives the Program Derived Address (PDA) for the wallet account and validates that it matches the provided wallet account.
- Creates a new `Wallet` struct with an initial amount of 0 and `initialized` set to true.
- Calculates the rent-exempt balance for the wallet account.
- Invokes the system program to create the wallet account, signing with the PDA's bump seed.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Deposits an amount into the wallet account.
- Retrieves account information: user account and wallet account.
- Checks that the wallet account owner is the program itself, and that the user account is a signer.
- Derives the PDA for the wallet and validates that it matches the provided wallet account.
- Deserializes the `Wallet` struct from the wallet account's data.
- Adds the specified `amount` to the `wallet.amount`.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "withdraw_amount":
- Withdraws an amount from the wallet account.
- Retrieves account information: user account and wallet account.
- Checks that the wallet account owner is the program itself, and that the user account is a signer.
- Derives the PDA for the wallet and validates that it matches the provided wallet account.
- Deserializes the `Wallet` struct from the wallet account's data.
- Subtracts the specified `amount` from the `wallet.amount`.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Transfers an amount from one wallet account to another.
- Retrieves account information: user account, source wallet account, destination user account, and destination wallet account.
- Checks that both source and destination wallet account owners are the program itself, and that the user account is a signer.
- Derives the PDAs for both source and destination wallets and validates that they match the provided wallet accounts.
- Deserializes the `Wallet` structs from both source and destination wallet account data.
- Adds the specified `amount` to the `dest_wallet.amount`.
- Subtracts the specified `amount` from the `src_wallet.amount`.
- Serializes the updated `Wallet` structs back into their respective wallet account data.
