Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the unpacked instruction and calls the corresponding function.
- Dispatches to `initialize_wallet_account`, `deposit_amount`, `withdraw_amount`, or `transfer_amount` based on the instruction.

Function "initialize_wallet_account":
- Retrieves accounts from the `accounts` slice using an iterator. It expects the user account, the wallet account, and the system program account.
- Checks if the user account is a signer. Returns an error if not.
- Derives the PDA for the wallet account using `Pubkey::find_program_address`.
- Validates that the provided wallet account matches the derived PDA. Returns an error if they don't match.
- Creates a `Wallet` struct with an initial amount of 0 and `initialized` set to true.
- Calculates the rent required for the wallet account.
- Invokes the system program to create the wallet account, passing the required rent and account size. Uses a signed invocation with the PDA bump seed.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Retrieves accounts: user account and wallet account.
- Checks if the user account is a signer.
- Derives the PDA for the wallet account and validates that the provided wallet account matches the derived PDA.
- Deserializes the `Wallet` struct from the wallet account's data.
- Increases the wallet's `amount` by the specified `amount`.
- Serializes the updated `Wallet` struct back into the wallet account's data.
- Potential vulnerability: Integer overflow in `wallet.amount += amount;`.

Function "withdraw_amount":
- Retrieves accounts: user account and wallet account.
- Checks if the user account is a signer.
- Derives the PDA for the wallet account and validates that the provided wallet account matches the derived PDA.
- Deserializes the `Wallet` struct from the wallet account's data.
- Checks for sufficient funds before withdrawing. Returns `ProgramError::InsufficientFunds` if the wallet balance is less than the withdrawal amount.
- Subtracts the specified `amount` from the wallet's `amount` using `checked_sub` to prevent underflow.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Retrieves accounts: user account, source wallet account, destination user account, and destination wallet account.
- Checks if the user account is a signer.
- Derives the PDAs for both the source and destination wallet accounts. Validates that the provided wallet accounts match the derived PDAs.
- Deserializes `Wallet` structs from both the source and destination wallet account data.
- Adds the transfer `amount` to the destination wallet's `amount`. This operation is vulnerable to integer overflow.
- Checks for sufficient funds in the source wallet before transferring.
- Subtracts the specified `amount` from the source wallet's `amount` using `checked_sub` to prevent underflow.
- Serializes the updated `Wallet` structs back into their respective account data.
- Potential vulnerability: Integer overflow in `dest_wallet.amount += amount;`.
