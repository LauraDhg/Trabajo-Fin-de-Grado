Function "process_instruction":
- Unpacks the instruction data into an `InstructionFormat` enum.
- Matches the unpacked instruction to call the corresponding handler function: `initialize_wallet_account`, `deposit_amount`, `withdraw_amount`, or `transfer_amount`.

Function "initialize_wallet_account":
- Initializes a new wallet account for a user.
- Retrieves accounts from the `accounts` slice using an iterator. It expects a user account (signer), a wallet account, and the system program account.
- Checks if the user account is a signer.
- Derives the Program Derived Address (PDA) for the wallet account using `Pubkey::find_program_address`. The seed is "wallet" and the user account's public key.
- Checks if the wallet account already has lamports. If so, it returns an error.
- Creates a `Wallet` struct with an initial amount of 0 and sets `initialized` to true.
- Calculates the rent exemption balance for the wallet account.
- Invokes the system program to create the wallet account using `invoke_signed`.
- Serializes the `Wallet` struct into the wallet account's data.

Function "deposit_amount":
- Deposits lamports into the wallet account.
- Retrieves accounts from the `accounts` slice using an iterator. It expects a user account (signer) and a wallet account.
- Checks if the user account is a signer.
- Deserializes the wallet account's data into a `Wallet` struct.
- Checks if the wallet is initialized.
- Adds the deposit amount to the wallet's `amount` field using `checked_add` to prevent arithmetic overflows.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "withdraw_amount":
- Withdraws lamports from the wallet account.
- Retrieves accounts from the `accounts` slice using an iterator. It expects a user account (signer) and a wallet account.
- Checks if the user account is a signer.
- Deserializes the wallet account's data into a `Wallet` struct.
- Checks if the wallet is initialized.
- Checks for sufficient funds before withdrawing.
- Subtracts the withdrawal amount from the wallet's `amount` field using `checked_sub` to prevent arithmetic overflows.
- Serializes the updated `Wallet` struct back into the wallet account's data.

Function "transfer_amount":
- Transfers lamports from one wallet account to another.
- Retrieves accounts from the `accounts` slice using an iterator. It expects a user account (signer), a source wallet account, a destination user account, and a destination wallet account.
- Checks if the user account is a signer.
- Deserializes both the source and destination wallet account data into `Wallet` structs.
- Checks if both wallets are initialized.
- Adds the transfer amount to the destination wallet's `amount` field using `checked_add` to prevent arithmetic overflows.
- Checks for sufficient funds in the source wallet before transferring.
- Subtracts the transfer amount from the source wallet's `amount` field using `checked_sub` to prevent arithmetic overflows.
- Serializes the updated `Wallet` structs back into their respective wallet account's data.
