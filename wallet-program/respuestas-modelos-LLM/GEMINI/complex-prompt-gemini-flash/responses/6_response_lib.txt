Function "process_instruction":
- The `process_instruction` function acts as the main entry point for handling different instructions. This function is crucial as it dictates how the program reacts to various user inputs.

Function "initialize_wallet_account":
- Checks if the provided `system_program` account is the actual System Program. If not, it returns an `InvalidArgument` error.
- Uses `Pubkey::find_program_address` to derive the PDA for the wallet, ensuring that the provided `wallet_account` matches the derived PDA.
- Checks if the `wallet_account` already has lamports, preventing accidental re-initialization.
- Creates a new account using `invoke_signed`, transferring the rent-exempt amount from the `user_account` to the `wallet_account`. The seed used to derive the PDA is passed to `invoke_signed` ensuring that only the program can create the account at the derived address.
- Serializes the `Wallet` struct into the newly created `wallet_account`.

Function "deposit_amount":
- Checks if the `wallet_account` owner matches the program ID to ensure only the program can modify the account.
- Uses `Pubkey::find_program_address` to derive the PDA for the wallet, ensuring that the provided `wallet_account` matches the derived PDA.
- Deserializes the `Wallet` struct from the `wallet_account`.
- Performs a checked addition of the deposit `amount` to the `wallet.amount` using `checked_add`, returning an `ArithmeticError` if an overflow occurs.
- Serializes the updated `Wallet` struct back into the `wallet_account`.

Function "withdraw_amount":
- Checks if the `wallet_account` owner matches the program ID to ensure only the program can modify the account.
- Uses `Pubkey::find_program_address` to derive the PDA for the wallet, ensuring that the provided `wallet_account` matches the derived PDA.
- Deserializes the `Wallet` struct from the `wallet_account`.
- Checks if the `wallet` has enough balance to withdraw the specified `amount`, returning an `InsufficientFunds` error if the balance is insufficient.
- Performs a checked subtraction of the withdrawal `amount` from the `wallet.amount` using `checked_sub`, returning an `ArithmeticError` if an underflow occurs.
- Serializes the updated `Wallet` struct back into the `wallet_account`.

Function "transfer_amount":
- Checks if both the `src_wallet_account` and `dest_wallet_account` owners match the program ID, ensuring only the program can modify the accounts.
- Uses `Pubkey::find_program_address` to derive the PDAs for both the source and destination wallets, ensuring that the provided accounts match the derived PDAs.
- Deserializes the `Wallet` struct from both the `src_wallet_account` and `dest_wallet_account`.
- Performs a checked addition of the transfer `amount` to the `dest_wallet.amount` using `checked_add`, returning an `ArithmeticError` if an overflow occurs.
- Checks if the `src_wallet` has enough balance to transfer the specified `amount`, returning an `InsufficientFunds` error if the balance is insufficient.
- Performs a checked subtraction of the transfer `amount` from the `src_wallet.amount` using `checked_sub`, returning an `ArithmeticError` if an underflow occurs.
- Serializes the updated `Wallet` struct back into both the `src_wallet_account` and `dest_wallet_account`.
